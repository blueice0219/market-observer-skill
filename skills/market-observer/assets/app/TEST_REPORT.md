## 测试覆盖

- UTF-8 BOM、GB18030 CSV；JSON records/envelope/split/columns/index/table；JSONL。
- 股票代码前导零、交易所前后缀、非法代码拒绝；百分数、千分位、NaN/Inf/null；手到股单位换算。

- 分页、搜索、交易所过滤、稳定排序、榜单忽略缺失值、快照版本冲突。
- 无数据和过期状态、require_fresh、404/422、认证、CORS 预检及错误响应、内部错误不泄露堆栈。
- 真实子进程互斥锁、线程并发读写完整性、来源切换、最小行数和覆盖骤降检查。
- 子进程超时处理路径、历史保留数量、JSON/CSV 导出回读一致性、旧文件修改时间保持。
- CLI 单次采集与两个 API 进程读取同一 SQLite 数据库。

## 已知限制

1. 测试中有 **1 条依赖弃用警告**：Starlette TestClient 提示未来改用 httpx2。当前固定依赖组合下测试通过；这不是生产 HTTP 服务错误。此包仍使用 httpx 0.28.1 运行测试，未隐藏警告。
2. Linux 文件锁分支尚无本机执行证据；GitHub Actions 配置包含 Ubuntu/Windows × Python 3.11/3.14，需要将项目提交到仓库后实际执行。
3. 行情源是网页行情适配，未验证交易所时间或证券主表完整性；默认阈值只用于识别明显的空结果和覆盖骤降。
4. 未恢复原 ZIP 源码，本项目按历史需求重建，提供旧数据文件导入兼容层；未知的原项目专有功能无法逐项核对。
5. 不包含公网压测、交易执行、Level-2、精确节假日日历或付费行情 SLA。

## 复现

在项目根目录，使用已安装依赖的虚拟环境解释器执行：

```text
python -m pytest -q
python scripts/smoke_http.py
python -m a_share_monitor doctor --source sina --timeout 180
python -m a_share_monitor collect --source auto --once
python -m a_share_monitor serve
```

最后两条应在不同终端运行；请在两个终端设置相同 MONITOR_DB。实时网络测试与离线测试分开，不在 CI 中反复请求行情站点。
