# 观市 · 图形界面使用说明

此版本在原来的本机采集和 HTTP API 上增加中文图形界面。Windows 可以通过 Edge 应用窗口打开，也可以直接在浏览器使用；它是本机网页工作台，不是内置独立浏览器引擎的 EXE 安装包。

## 打开

完成安装后，在部署目录双击 `open_ui.cmd`，检查并启动本项目的 API 和采集器，然后打开应用窗口。可自行为此文件创建桌面快捷方式。

服务运行时直接访问：[http://127.0.0.1:8000/](http://127.0.0.1:8000/)。已有 API 地址继续可用。

Linux 按 README 启动 API 与采集器，然后在浏览器打开相同地址。

## 功能

- **全市场行情**：沪/深/京过滤，名称或代码搜索，点击表头排序，每页 25 只。
- **股票详情**：点击股票名称，查看价格、涨跌、今开、昨收、高低价、成交量/额及来源时间。
- **我的自选**：点击 ☆ 收藏，点击 ★ 取消。自选只保存在当前浏览器，同一电脑不同浏览器之间不共享。
- **市场排行榜**：涨幅、跌幅、成交额和成交量榜，基于同一快照排序，支持市场过滤及搜索。
- **市场温度**：按全市场快照统计上涨、下跌、平盘和涨跌幅区间；不是指数或历史趋势图。
- **导出 CSV**：导出当前筛选结果的全部行，不只当前页。代码带前导单引号以尽量保留前导零；这是面向表格软件的导出，重新导入采集器请使用命令行 `export` 生成标准 CSV/JSON。
- **数据与状态**：显示来源、采集时间、连续失败次数和最近错误。陈旧、离线示例和请求失败均有明显提示。
- **连接设置**：服务启用 API Key 时填写；密钥仅存于当前页面内存。

页面默认每 30 秒读取本机快照，不触发外部抓取。关闭自动刷新后仍可手动读取。采集器仍按原先约 5 分钟的轮询配置工作。界面关闭不会停止后台采集；需要停止时运行 `stop_local.cmd`。

界面使用本地静态资源，不加载远程字体、图表库或 CDN。行情来源本身仍需联网。缺失数据用 — 表示，不补造 K 线或收益走势；采集时间不代表交易所最新成交时间。

## 本次验证

2026-10-15，Windows：50 项后端/静态资源测试通过；浏览器中实测显示 5575 只股票，并验证搜索、详情、自选增删、排行榜切换。自选测试项已移除。桌面尺寸及窄窗口布局均已检查。

历史快照数据库、运行日志和虚拟环境不放入分发 ZIP。其他电脑使用前仍需按 README 安装依赖；本机已经安装，无需重复安装。
