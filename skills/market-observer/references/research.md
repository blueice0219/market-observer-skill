# 个股研究工作流

## 明确对象与截止时间

确认股票代码与公司名称一致。用户未给观察周期时可先以“近期消息 + 中期经营”综合视角推进，并写清范围；不自行假设其仓位、成本、风险承受能力。记录上海时间的截止时间和数据覆盖范围。

## 取得行情证据

在 Skill 根目录运行：

```text
python scripts/research_bundle.py --code 000001 --out /path/to/research/quote-evidence.json
```

默认只访问本机服务，`--base-url` 指定实际可达的服务；密钥从 MONITOR_API_KEY 环境变量读取。JSON 保存行情、行情元数据和服务状态，不含模型密钥，也不会主动调用任何 AI 模型。

## 补齐资料

使用当前宿主 Agent 真正具备的搜索、浏览或数据工具。不要求特定付费供应商，不因安装本 Skill 而假定已联网。

- 公告、定期报告：交易所、公司投资者关系页、巨潮资讯。记录披露日、报告期、原文 URL、页码/表格位置。
- 新闻与政策：核对原始报道及正式政策文件，记录发布时间、事件日期；转载去重，核对是否真正指向该公司。
- 历史行情：需行情源实际返回的日线，标注前复权/后复权/不复权；除权前后不要混算。缺历史序列不生成均线/波动率。
- 财务：收入、利润、经营现金流、负债等保留原单位。同比口径一致，负基数增长率说明经济意义；不混淆累计季度和单季度。
- 行业和估值：明确可比公司及选择理由、估值日期、TTM/年度口径；亏损公司的 PE 不直接按便宜或贵解释。

AKShare 可作为结构化数据工具，接口实时可用性需实测：[官方股票数据文档](https://akshare.akfamily.xyz/data/stock/stock.html)。个股新闻检索不是完整历史新闻库。每个失败来源最多进行一次有针对性的修正重试；仍失败记录缺口，使用可验证的替代来源或缩小报告。

## 证据与分析

来源编号 S1、S2…；每项核心判断引用证据编号。仅本地行情 URL 不能作为所有新闻/财务结论的来源。计算写出公式与输入口径，可用表格或程序复核。

先陈述事实，再解释影响机制和反向证据。消息出现与价格变化的时间相关不等于因果。传闻不升级为事实；媒体情绪不能替代盈利预测。使用条件化情景，不给无依据的涨跌概率、目标价或确定买卖指令。

根据 [报告结构](report-format.md) 交付 Markdown 报告和证据清单。工具缺失时标注“本次未核实”，不要声称全方位覆盖。PDF 为按需产物，只有实际生成并验证后才报告已导出。
