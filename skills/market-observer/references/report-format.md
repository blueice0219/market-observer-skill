# 个股观察报告结构

文件名建议 `股票代码_YYYYMMDD_HHMMSS_观察报告.md`。保留用户关注问题，不要求机械凑齐篇幅；无数据的模块写缺口和影响。

1. **报告信息**：股票/公司、研究问题、观察周期、截止时间、最新价格时间口径、demo/stale/覆盖限制。
2. **核心结论**：3–5 个有证据的发现，标注事实/推断；列出对判断影响最大的未知项。
3. **业务与行业**：收入来源、行业位置、竞争与可比公司，不能只罗列概念板块标签。
4. **财务与估值**：经营趋势、利润与现金流一致性、资产负债风险、估值口径；附关键数字表与期间/单位。
5. **公告与消息时间线**：事件、发布日期、事实摘要、潜在影响路径、证据等级、来源。
6. **量价观察**：实际取得的行情与确定性指标，标注复权与观察区间；没有历史数据则仅讨论快照字段。
7. **情景与反证**：乐观/基准/悲观的触发条件、观察信号、判断失效条件，不伪造概率。
8. **后续观察清单**：财报、订单、政策、解禁等明确事件；区分已公布日期与估计日期。
9. **证据与限制**：来源编号、标题、发布/抓取日期、URL/文档页码；列出失败接口、缺失资料和冲突来源。

保存每次报告版本，不覆盖旧报告来使过去的判断看起来更准确。不要把历史回测、未经校准的评分与真实预测表现混为一谈。
